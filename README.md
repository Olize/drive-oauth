# Olize Drive OAuth

Public information page and privacy policy for private rclone-based Google Drive access on devices owned by the account holder.

The website does **not** handle Google login, API credentials, OAuth tokens, or Drive files.

GitHub Pages: https://olize.github.io/drive-oauth/

These OAuth clients are for personal use only, not a public service.
