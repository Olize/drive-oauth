Privacy Policy — Olize Drive Access

Last updated: 20 October 2026

This private, non-commercial Google Drive integration is operated solely for the account holder's personal use via rclone. It is not offered to external users.

Google data accessed

Depending on the OAuth client selected by the account holder, rclone can access file and folder names, metadata, and contents in Google Drive. The read/write client can also create, modify, and delete files in the account holder's Drive. The read-only client can list and read files but cannot modify them through the granted OAuth permission.

Data use and storage

Google Drive data is accessed only to display, stream, mount, or manage files for the account holder. rclone processes it locally on devices under the account holder's control; temporary local caches may be used. OAuth tokens and client credentials are stored in protected local configuration files, not in this website. The website does not collect Google Drive contents, transmit them to the site operator, or use them for advertising, analytics, AI training, or resale.

Sharing

The application does not transfer Google user data to any external backend or third party for independent use. Google handles Google Drive requests through its own infrastructure. The account holder controls any files that they intentionally share using Google Drive features.

Retention, access, and deletion

Local rclone caches and OAuth credentials are retained on the account holder's own devices until removed. Drive file retention is controlled by the account holder's Google Drive settings. The account holder can delete local credentials, stop rclone, and revoke app permissions via Google Account settings. This static website does not hold any Drive data that could be retrieved or deleted from it.

Website hosting

This website is hosted by GitHub Pages. GitHub may process technical access data (such as IP addresses or browser information) according to GitHub's privacy statement. There are no analytics scripts, cookies set by page code, or OAuth handlers on this website.

Contact

For questions about this page, contact the maintainer through the public GitHub repository. Do not post passwords, OAuth tokens, or private Google Drive information.

Datenschutzerklärung (Deutsch)

Diese nichtkommerzielle Google-Drive-Anbindung wird ausschließlich privat durch den Kontoinhaber mit rclone genutzt. Abhängig vom OAuth-Client kann rclone Dateien und Metadaten lesen beziehungsweise Dateien erstellen, verändern und löschen. Die Verarbeitung erfolgt auf eigenen Geräten des Kontoinhabers. Zwischenspeicher sowie OAuth-Zugangsdaten werden lokal auf diesen Geräten aufbewahrt; diese Webseite speichert weder Google-Drive-Daten noch Tokens, setzt selbst keine Tracking-Skripte und stellt keinen OAuth-Login bereit.

Die Daten werden ausschließlich für Dateizugriff, Streaming und Verwaltung durch den Kontoinhaber verwendet, nicht für Werbung, Verkauf oder KI-Training. Der Kontoinhaber kann den Zugriff jederzeit in den Google-Kontoeinstellungen widerrufen und lokal gespeicherte Daten löschen. Die Webseite wird durch GitHub Pages gehostet. GitHub kann technische Zugriffsprotokolle nach seiner Datenschutzerklärung verarbeiten.
