Olize Drive Access

A private, non-commercial Google Drive integration using rclone.

Not a public service: this OAuth application is used only by the Google account holder on personally controlled devices. This site does not provide a login, store tokens, or proxy Google Drive traffic.

Purpose and permissions

The Google Drive API is used to mount or access the account holder's Drive files. Separate OAuth clients can be configured for:

  • VM01 — read/write: access to view, create, modify, and delete files via rclone (drive scope).
  • Android TV — read-only: access to list and read files via rclone (drive.readonly scope).

Each OAuth consent is granted by the account holder. Permissions can be revoked at any time in Google Account third-party connections.

How it works

Google authentication happens directly between Google and rclone. OAuth credentials remain in the device's local configuration. This GitHub Pages website is an information page only and contains no login code, analytics, tracker, or access to Drive files.
